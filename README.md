## Project Overview
Analyzed retail sales, customer, product, and store data using PostgreSQL and Power BI.

## Tools
* PostgreSQL 
* Power BI
* CSV

## Power BI Dashboard
The dashboard includes:

* Total Sales
* Total Net Sales
* Total Profit
* Total Quantity Sold
* Sales by Month
* Sales by Store
* Net Sales by Region
* Top 5 Products by Net Sales
* Total Profit by Category
* Payment Mode Analysis
* Region & Category Analysis

## SQL Analysis
Used SQL for:

* Sales and profit analysis
* Customer and membership analysis
* Product and category analysis
* Store and regional analysis
* Filtering and sorting
* Aggregation and grouping
* JOINs
* GROUP BY and HAVING
* Subqueries
* Date-based analysis

## Objective
To analyze retail business performance and identify key sales, customer, product, and store insights using PostgreSQL and an interactive Power BI dashboard.

## About
Retail sales data analysis using PostgreSQL and Power BI.
